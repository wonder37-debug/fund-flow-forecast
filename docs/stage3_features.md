# 阶段三多步训练样本与特征

每个样本的键为 `(origin, report_date)`，其中 `origin` 是最后一个已知交易日，`report_date` 是目标日。从至少 84 天连续历史起步，每个历史截止点最多展开 31 个预测跨度。`build_examples` 仅生成特征，通过 public calendar 获取目标日字段。训练折再按 `report_date <= fold.cutoff` 连接已观测标签。拟合和预测处理申购与赎回两个独立目标，第一批模型只接收显式特征组。

| 特征组 | 含义和可用时间 |
| --- | --- |
| `calendar` | 目标星期 one-hot、假期、补班、节前后、实际工作状态、月末三日、`horizon_day`。未来字段由已经公布的日历生成。 |
| `lags` | 截止日、截止日前 7 日、最近和上一个目标同星期的历史金额。分母是对应金额在截止日前含当天的 28 日均值，下限 1 分。 |
| `rolling` | 截至该样本的 7 日均值、28 日中位数、56 日均值，使用相同近期金额尺度。 |
| `trend` | 最近一周与前一周、最近四周与前四周的金额均值之比。 |
| `statistical` | `B3`、`cal_workday`、`blend_equal`、`trimmed_weekday` 和 `route_special` 的前向预测除以 28 日尺度。每个样本各自用当时已知历史重新拟合。原始预测分值独立存储用于残差还原和对照。 |
| `business` | 28 日历史银行卡申购占比、转出占赎回比、7/28 日观察人数及赎回交易人数之比。 |
| `external` | 余额宝七日收益指标 `mfd_7daily_yield` 和隔夜 `Interest_O_N` 在最近 7 个自然日的历史均值。缺失历史由训练中位数处理，首轮仅作消融。 |

同一真实日期的样本在每个模型的有效训练区间内合计权重为 1。样本对未来日期不可见的信息无法由训练输入接口传给预测。填补及标准化仅使用该折训练数据，未来未知目标、人数、余额、渠道及利率均未参与未来输入。特征缓存放在 `data/cache/stage3-features/`，按可用训练输入、源码、依赖与日历指纹区分。

直接预测分别比较原尺度金额、对数金额及相对 28 日尺度的金额；残差方法对比加法和对数比值，两者最终都恢复成分。默认只对普通日学残差，特殊日期保持统计预测。相对 MAE 的 LightGBM 对照使用训练期正金额中位数的一半作为倒数权重分母下限，比例空间另按尺度修正权重。该损失是带限相对误差代理。 [MAPE 与加权 MAE](https://arxiv.org/abs/1605.02541) · [候选配置](../configs/stage3.json)
