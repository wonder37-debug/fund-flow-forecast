# 资金流入流出预测 · 探索性数据分析

历史覆盖 **2013-07-01 至 2014-08-31，共 427 个连续自然日**，预测窗口为 **2014-09-01 至 09-30**。最稳定的信号是周内规律和节假日低谷。2014 年 6–8 月，申购日均大致持平，赎回日均连续回落，主要对应转出减少。拟合与验证应分别处理申购和赎回，并优先检验最近月份、同星期历史与已知日历的组合。

运行 `python -m src.eda` 可以从预处理后的 `daily.parquet` 和 `transactions.parquet` 重建 [聚合统计](../results/eda/) 与 [图表](../results/figures/)。聚合 CSV 的金额单位为分。下文按需要换算成百万元或元。Pearson 和 Spearman 都是样本内关联。29 日居中中位数和整段 STL 只用于历史诊断，预测计算使用对应截止日以前的数据。

稳健 STL 将 `log(1 + amount)` 分成趋势、七日季节项和残差。原始序列的 ADF p 值为申购 0.489、赎回 0.595，KPSS 均 ≤0.01。单独取 log 后，赎回 ADF 为 0.019，而 KPSS 仍 ≤0.01，两个检验给出不同信号。做 log 一阶差分或七阶差分后，两条序列的 ADF 均 <0.001，KPSS 均 ≥0.10。ADF 的原假设是存在单位根，KPSS 的原假设是水平平稳。结果支持在验证中比较 log、差分或移动尺度，节假日和阶段变化仍可能影响检验。 [图 2](../results/figures/eda_02_log_stl.png) · [平稳性检验](../results/eda/stationarity.csv)

全期申赎同日 Pearson 为 0.732，log 一阶差分后为 0.434。2014 年 6–8 月原始同日相关为 0.479，按月为 0.398、0.600、0.566。去掉 log STL 趋势和周周期后，6–8 月同日相关降到 0.132，申购领先 1/7/14/28 日与赎回残差的相关分别为 −0.079/−0.051/0.040/−0.152。两者共享部分季节和规模变化，短期残差联动弱且变号。跨目标滞后可作为消融项，先分别建立两条预测基线。 [申赎关联](../results/eda/flow_associations.csv)

## 5. 基金收益率与 SHIBOR

两列基金收益覆盖 427 日，所有 8 个期限的 SHIBOR 覆盖 294 日，最后有值日为 2014-08-29。原始文件内 9 月没有真实收益率和 SHIBOR。对每列分别算原始值和一阶日差分与申赎的 Pearson、Spearman，比较 0/1/3/7/14/28 日滞后及分段表现。滞后按自然日计算，利率缺口保持缺失，差分跨缺口也缺失。正滞后表示利率时间早于目标。

| 同日 Pearson 示例 | 申购，原始 / 差分 | 赎回，原始 / 差分 |
| --- | ---: | ---: |
| 全期万份日收益 | 0.44 / 0.13 | 0.05 / 0.14 |
| 全期七日收益 | 0.43 / 0.08 | 0.04 / 0.01 |
| 全期 SHIBOR 隔夜 | −0.23 / 0.09 | −0.45 / 0.08 |
| 全期 SHIBOR 一年 | 0.76 / 0.02 | 0.86 / 0.04 |

一年 SHIBOR 与赎回原始关联 0.86，差分降到 0.04，且夏季该期限样本内无变化，相关系数缺失。隔夜利率与申购的原始关联在 2013 下半年、2014 年 1–5 月、6–8 月分别是 0.41、0.43、−0.20。万份日收益与赎回同日差分的阶段相关为 0.18、0.33、0.27，仍属于预测日当天才观察的量。所有差分组合中，全期绝对 Pearson 最大的申购关系是 1 月 SHIBOR 同日 0.231，当项 Spearman 约 0.050。原始高相关可能部分来自共同趋势、政策周期或日历且相关随阶段变化。先建无外生变量基线，测试真实可得的历史滞后，固定月初预测时对其余天数采用冻结、单独预测或情景值。 [图 9](../results/figures/eda_09_rates.png) · [外部覆盖](../results/eda/rate_coverage.csv) · [关联与样本量](../results/eda/rate_associations.csv)

## 7. 三个自主研究方向

| 研究方向 | 支持证据 | 反证和边界 | 后续验证 |
